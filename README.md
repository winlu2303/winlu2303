### 🌟 Projects

  - Mock external server with up to 60s delay
  - Request history persisted in PostgreSQL
  - REST API with validation, optional JWT auth
  - Ready-to-use Docker containers and full test environment
  - [Code Repository](https://github.com/winlu2303/cadastral-service)

- **Event Analytics Service** — Real-time event collection and analytics in Go.
  - Microservice architecture with **Kafka → Consumer → ClickHouse**
  - JWT + Refresh auth, project & API key management
  - Event tracking (page_view, click, purchase, etc.)
  - Redis caching, Prometheus metrics, Grafana dashboards
  - CSV / JSON export
  - [Code Repository](https://github.com/winlu2303/event-analitycs-service)

  - PostgreSQL 15, Gorilla Mux, Testify, Docker Compose
  - [Code Repository](https://github.com/winlu2303/wallet-service)
